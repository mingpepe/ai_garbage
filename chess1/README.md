# 西洋棋大師 (Chess Master Web App)

一個功能完備、美觀流暢的現代西洋棋（國際象棋）Web 應用程式。支援電腦對戰、雙人同機對戰、全功能悔棋回溯、即時子力計分、局勢評估條以及包含「義大利開局」在內共 12 套經典名局的互動教學系統。

---

## 🌟 核心特色功能

### 1. 🤖 電腦 AI 對戰 (vs AI)
- **自由選擇陣營**：可自由切換執**白方（先手）**或執**黑方（後手）**。
  - 當玩家選擇執黑方時，棋盤會自動翻轉（黑方在下方），白方 AI 會立即走出第一步！
- **五個等級 AI 難度與多元隨機走法（Elo 800 ~ 2000+）**：
  - **等級 1 新手 (Beginner ~800)**：單步評估，35% 機率走隨機漏著（Blunder），高隨機溫度（$T=2.2$），走法多變且非常適合零基礎新手練習。
  - **等級 2 休閒 (Casual ~1100)**：2 層深度搜尋，35% 開局庫覆蓋，15% 輕微失誤，隨機溫度（$T=1.5$），偶爾漏子但有基本吃子意識。
  - **等級 3 中級 (Intermediate ~1400)**：3 層 Minimax 深度搜尋，85% 開局庫覆蓋，不故意送子，評估窗口 45 cp，溫度（$T=0.8$）讓局勢相近的優選著法保持高度隨機變化。
  - **等級 4 進階 (Advanced ~1700)**：3~4 層深度 + 靜態搜尋 (Quiescence Search) + MVV-LVA 著法排序，100% 開局庫，嚴謹戰術計算，評估窗口 25 cp，溫度（$T=0.4$）。
  - **等級 5 大師 (Master ~2000+)**：4~5 層深層搜尋 + 靜態搜尋 + MVV-LVA + 開局庫完整支援，評估窗口 12 cp，溫度（$T=0.2$）在微小分差的最強變例間隨機抽樣，杜絕定式背誦與死板走法。
  - 📖 **詳細實作與演算法原理**：完整數學公式與架構請參閱 [AI 難度等級與隨機性演算法文件 (AI_DIFFICULTY.md)](./AI_DIFFICULTY.md)。
- **思考狀態指示**：AI 走棋時呈現即時脈衝指示，不阻斷網頁渲染。

### 2. 👥 雙人對戰模式 (Pass & Play)
- 兩位玩家可使用同一台裝置在同一個螢幕輪流走棋。
- **輪流自動翻轉棋盤**：可開啟/關閉自動翻轉，方便面對面對弈。

### 3. 📊 計分與局面評估系統
- **子力分值統計**：
  - 兵 (Pawn) = 1 分
  - 騎士 (Knight) = 3 分
  - 主教 (Bishop) = 3 分
  - 城堡 (Rook) = 5 分
  - 皇后 (Queen) = 9 分
- **吃子展示與淨勝分標籤**：雙方吃掉的棋子即時以迷你向量圖標陳列，並標記目前子力領先優勢（例如：白方 +3、黑方 +2）。
- **即時局勢評估條 (Evaluation Bar)**：類似 Chess.com / Lichess，即時評估當前局勢的勝率與數值（例如：`+1.4` 表示白優、`-0.8` 表示黑優）。
- **對局比分統計 (Scoreboard)**：紀錄白勝、黑勝、和局次數，資料自動保存於瀏覽器 LocalStorage。

### 4. ⏪ 悔棋回溯功能 (Undo all the way to start)
- **無限制步數悔棋**：點擊「悔棋 (退回一步)」，人機對戰模式會自動退回電腦與玩家的行棋，**一路反悔退回到開局最開始（第 0 步初始局面）**！
- **快速跳轉導航**：
  - `⏪ 最開始`：一鍵回到初始棋盤。
  - `◀ 悔棋`：退回上一步。
  - `重做 ▶`：重新前進下一步。
  - `最新 ⏩`：跳至最新局勢。
- **互動式 PGN 著法表記**：即時顯示標準代號（如 `1. e4 e5 2. Nf3 Nc6`），**點擊表記中任意一手棋即可直接跳轉回該時刻局面**！

### 5. 🎓 開局教學模式 (12 套完整經典名局)
包含詳細的逐步引導、戰術背景剖析、動態高亮與綠色方向箭頭、走對推進與走錯提示、示範走步等：
1. **義大利開局 (Italian Game / Giuoco Piano)** - 1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. c3 Nf6 5. d4
2. **西班牙開局 (Ruy Lopez / Spanish Game)** - 1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 4. Ba4 Nf6 5. O-O
3. **西西里防禦 (Sicilian Defense - 那道爾夫變例)** - 1. e4 c5 2. Nf3 d6 3. d4 cxd4 4. Nxd4 Nf6 5. Nc3 a6
4. **法蘭西防禦 (French Defense)** - 1. e4 e6 2. d4 d5 3. Nc3 Nf6 4. Bg5 Be7 5. e5 Nfd7
5. **卡羅-康防禦 (Caro-Kann Defense)** - 1. e4 c6 2. d4 d5 3. Nc3 dxe4 4. Nxe4 Bf5 5. Ng3 Bg6
6. **后翼棄兵 (Queen's Gambit - 拒吃后翼棄兵 QGD)** - 1. d4 d5 2. c4 e6 3. Nc3 Nf6 4. Bg5 Be7 5. e3 O-O
7. **王翼棄兵 (King's Gambit - 浪漫主義刺殺風暴)** - 1. e4 e5 2. f4 exf4 3. Nf3 g5 4. Bc4 g4 5. O-O
8. **國王印度防禦 (King's Indian Defense - 超現代主義)** - 1. d4 Nf6 2. c4 g6 3. Nc3 Bg7 4. e4 d6 5. Nf3 O-O
9. **斯堪地那維亞防禦 (Scandinavian Defense - 直接宣戰)** - 1. e4 d5 2. exd5 Qxd5 3. Nc3 Qa5 4. d4 Nf6
10. **倫敦體系 (London System - 萬用金字塔堅固防線)** - 1. d4 d5 2. Bf4 Nf6 3. e3 c5 4. c3 Nc6 5. Nd2
11. **蘇格蘭開局 (Scotch Game - 第三步引爆中央)** - 1. e4 e5 2. Nf3 Nc6 3. d4 exd4 4. Nxd4 Bc5 5. Be3
12. **尼姆佐-印度防禦 (Nimzo-Indian Defense - 絕對牽制)** - 1. d4 Nf6 2. c4 e6 3. Nc3 Bb4 4. e3 O-O

### 6. 🎨 視覺與音效體驗
- **平滑棋子滑動動畫 (Smooth Piece Animation)**：
  - 電腦對戰走棋時具備人性化的自然思考停頓（550~750ms），不再瞬間生硬跳轉。
  - 棋子移動採用平滑 CSS `translate3d` 軌跡滑動動畫（280ms，貝茲曲線緩動），包含王車易位（國王與城堡同步滑行）與吃子淡出特效，視感行雲流水。
- **超大視覺與自適應畫面縮放 (Zoom Control)**：
  - 預設棋盤全面放大至 **740px**（原為 560px），每個棋格與向量棋子更寬廣清晰！
  - 頂部導航欄提供 **畫面縮放控制（`🔍−` 縮小、`🔍＋` 放大）**，支援「標準 (620px)」、「大 (740px)」、「特大 (850px)」、「超大 (960px)」自由切換，並自動記憶玩家喜好。
- **標準 Staunton 向量 SVG 棋子**：內嵌向量圖形，在任何放大倍率下皆銳利清晰不失真。
- **純 Web Audio API 合成音效**：內建走子、吃子、王車易位、將軍警示與將死終局音效，無需依賴外部音訊檔案，離線穩定播放。
- **兵的升變 (Pawn Promotion)**：提供皇后、城堡、主教、騎士圖形化彈窗選擇。
- **特殊走法與棋局終止判定**：
  - **王車易位 (Castling)**：全面支援短易位 (O-O) 與長易位 (O-O-O)。支援「移動國王兩格」、「點擊/拖曳國王到城堡上」或「點擊城堡再點擊國王」，棋盤會顯示醒目的 🏰 城堡圖標引導！
  - **吃過路兵 (En Passant)**：完全合乎國際標準規範。
  - **將軍紅框警示與將死判定 (Checkmate)**。
  - **完整逼和偵測 (Stalemate)**：嚴格依照國際象棋規則，當輪到走棋方未受將軍但盤面無任何合法步可走時，即時判定為「逼和 (Stalemate)」和局，並以專屬金色光暈標記困閉國王與彈窗詳細解說。
  - **三次重複局面與子力不足和局**自動判定。

## 🚀 啟動方式

本專案採用純原生現代 ES Modules 架構，可透過任何靜態網頁伺服器啟動：

### 方法一：使用專案內建指令 (Node / Python)
```bash
npm start
```
或直接執行：
```bash
python3 -m http.server 3000
```

### 方法二：在瀏覽器中開啟
在終端機啟動伺服器後，開啟瀏覽器訪問：
```
http://localhost:3000
```
或在具備本地伺服器支援的瀏覽器環境中直接預覽 `index.html`。
