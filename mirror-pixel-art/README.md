# 鏡像小畫家 (Mirror Pixel Art) 🎨

這是一個專為 5-6 歲小朋友設計的鏡像對稱畫畫遊戲。通過在畫布右側模仿左側的圖案，小朋友可以學習對稱的概念、色彩感知以及精細動作控制。

## 遊戲特色

### 1. 核心玩法
- **對稱畫布：** 畫布被中間的垂直線分割，左側為「範本」，右側為「創作區」。
- **鏡像邏輯：** 玩家點擊右側格子時，需要對準左側對應位置的顏色。
- **色彩選擇：** 下方提供豐富的色塊，點擊即可切換畫筆。

### 2. 互動反饋
- **視覺引導：** 滑鼠懸停時，對應的左側座標會高亮顯示，增強座標感。
- **動態特效：** 填色正確時會有「跳動 (Pulse)」動畫，顏色不符時會有「果凍 (Jelly)」晃動提醒。
- **Perfect 慶祝：** 完成對稱圖形後，會觸發彩色紙屑特效並顯示 "Perfect!" 動畫。

### 3. 難度系統
- **新手 (Easy)：** 6x6 網格，簡單幾何圖形。
- **進階 (Normal)：** 10x10 網格，如樹苗、愛心。
- **挑戰 (Hard)：** 14x14 網格，如蝴蝶等複雜對稱。

### 4. 獎勵機制
- **積分系統：** 正確填色獲得 10 分，完成關卡獲得 100 分。
- **勳章收集：** 根據完成情況解鎖「繪畫小天才」、「對稱大師」等稱號。

## 技術實作
- **框架：** React + TypeScript
- **動畫：** CSS Keyframes + `canvas-confetti`
- **佈局：** CSS Grid
- **圖示：** `lucide-react`

## 如何開始
```bash
cd mirror-pixel-art
npm install
npm run dev
```
打開瀏覽器訪問 `http://localhost:5173` 即可開始遊戲！
