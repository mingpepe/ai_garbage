# 🍎 兒童 2D 水果店經營 Web App (Kids Fruit Store)

一個專為 6 歲兒童設計的 2D 水果店經營遊戲。採用 **Vue 3 + TypeScript + Pinia + HTML5 2D Canvas** 開發。

---

## ✨ 核心特色

1. **絕對零文字（Zero-Text）兒童友善介面**：
   - 全程使用水果圖示 (🍎🍌🍊🍇🍓🍉🍑🍍🍒🥝)、代幣金幣 (🪙)、生動表情符號 (😊/😐/😣)、星光粒子特效與直覺動畫回饋。
2. **純鍵盤操作主遊戲流程**：
   - 移動：方向鍵 `↑` `↓` `←` `→` 或 `W` `A` `S` `D`
   - 互動 / 抓取 / 確認：`Space`
   - 收銀結帳：鍵盤左右選取數字或直接鍵盤輸入、`Space` / `Enter` 送出
3. **嚴格互斥背包狀態機 (PlayerCarryState)**：
   - `EMPTY`（空手）：可拿取水龍頭噴壺、撿起爛果、拿取空籃子。
   - `MIST_SPRAYER`（手持噴壺）：對枯萎貨架灑水保鮮；歸還水龍頭後恢復 `EMPTY`。
   - `ROTTEN_FRUIT`（手持爛果）：走到垃圾桶丟棄後恢復 `EMPTY`。
   - `BASKET_EMPTY`（背負空籃）：前往倉庫水果堆進入接水果小遊戲；歸還籃子架恢復 `EMPTY`。
   - `BASKET_FULL`（水果補貨箱）：小遊戲結算後狀態，至前台對應貨架補貨後轉為 `BASKET_EMPTY`。
4. **顧客生命週期與耐心機制**：
   - 自動巡迴挑選有庫存之水果，若全店無庫存則無奈離開店鋪。
   - 依等待時間動態切換耐心狀態：😊 $\to$ 😐 $\to$ 😣。
   - 結帳算錯時表情降階但不中斷遊戲，算對時收銀機彈開並掉落金幣與星星。
5. **工程模式與後台設定 (Admin Modal)**：
   - 點擊右上角齒輪 ⚙️ 圖標，輸入 PIN 碼 `1107` 解鎖繁體中文後台。
   - 可即時調整顧客生成頻率、購買量、耐心門檻、小遊戲時限與速度、10 種水果單價，並提供一鍵補滿貨架與一鍵生成顧客測試工具。

## 🗺️ 地圖與座標系統 ($16 \times 12$ 網格，單格 $48 \times 48\text{ px}$)

### 場景 A：前台店鋪 (`SHOP`)
- `(2, 1)`: 後門 🚪（通往倉庫）
- `(13, 1)`: 水龍頭與灑水壺放置區 🚿
- `(1, 4) ~ (5, 4)`: 水果架 1 ~ 5（上排：🍎 🍌 🍊 🍇 🍓）
- `(1, 7) ~ (5, 7)`: 水果架 6 ~ 10（下排：🍉 🍑 🍍 🍒 🥝）
- `(1, 10)`: 垃圾桶 🗑️
- `(11, 8)`: 收銀櫃台（玩家站位 `(11, 7)`，排隊點 `(11, 9) ~ (11, 11)`）
- `(14, 11)`: 店面大門 🚪（顧客出入口）

### 場景 B：後台倉庫 (`WAREHOUSE`)
- `(2, 1)`: 前台門 🚪（返回店鋪）
- `(2, 3)`: 籃子放置區 🧺（領取或歸還空籃子）
- `(5, 4) ~ (9, 4)`: 水果堆分區 1 ~ 5
- `(5, 8) ~ (9, 8)`: 水果堆分區 6 ~ 10

### 場景 C：接水果小遊戲 (`MINI_GAME`)
- 獨立下落物理場景。
- 頂部：環形倒數計時器與即時水果收集計數（例：🍎 x 8）。
- 底部：小貓背著籃子左右移動接水果。

## 🛠️ 開發與測試指令

```bash
# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev

# 執行 Vitest 單元測試與狀態機測試
npm run test:unit

# 執行 Playwright 端到端 (E2E) 測試
npm run test:e2e

# 生產環境建置
npm run build
```
